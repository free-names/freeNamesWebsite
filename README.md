# Free Names website

The site for Free Names: free subdomains on `meowed-at.me`, `is-a.stupid.cat`, `has-a.space` and `is-a.wiki`.

SvelteKit on Cloudflare Workers.

```sh
bun install
bun run dev
bun test
bun run build
```

Domains and their registry repos live in `src/lib/index.ts`.
